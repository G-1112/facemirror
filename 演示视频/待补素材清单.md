# 演示视频（提交前录制）

> 赛题未对小程序赛道强制要求视频时长，但「成果展示建议附演示录屏片段」，
> 且体验版/上线凭证为加分项。

## 建议结构（3-5 分钟）

1. 0:00-0:30 痛点引入：面试/答辩表达没人练、没人评
2. 0:30-1:30 主链路：抽题 → 录音 3 分钟（可加速）→ 出报告
3. 1:30-2:30 ★核心差异化：上传简历 → AI 生成针对材料的追问
4. 2:30-3:00 报告解读：雷达图 / 逐句批注 / 薄弱项诊断 / 同题重练
5. 3:00-3:30 分享海报 + 历史趋势
6. 3:30-4:00 落地规划一句话收尾

## 录制注意

- 真机录屏，1080p；
- 录音环节可用倍速，但要说明"实际需说满 3 分钟"；
- 若展示订阅消息，需先填好 `SUBSCRIBE_TEMPLATE_ID`。
