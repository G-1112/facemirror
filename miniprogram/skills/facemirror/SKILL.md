# 面试表达力练习

围绕「面镜」小程序的表达力训练：抽练习题目、查询练习历史、查看评估报告，并引导用户进小程序完成开口作答。

## 触发场景
用户原话举例（路由命中本技能）：
- "给我出道面试题练练嘴"
- "下周要答辩了，抽一道答辩的问题"
- "我上次模拟面试得了多少分？"
- "看看我最近的练习记录"
- "我之前那次评估报告里老师（AI）怎么点评的？"

## 不适用范围
- 想直接开口录音作答、要语音识别或重新生成评估报告 → 需进小程序内完成，本技能通过抽题后的卡片引导进入
- 想上传简历/论文材料生成针对性追问 → 在小程序内「自定义出题」完成，本技能不支持材料上传
- 修改某次练习的转写文本 → 在小程序内练习详情中操作

## 使用顺序
- `drawQuestion`：用户想练习、需要题目时调用；抽到题后引导用户点卡片进小程序开口作答。
- `getPracticeHistory`：用户询问练过几次、历史成绩时调用；各能力独立，无前置。
- `getPracticeReport`：用户想看某一次练习的得分与点评时调用；必须先由 `getPracticeHistory` 取得 recordId 后才可调用，不得向用户编造分数。
