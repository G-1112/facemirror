## 0. 凭据与配置清单（动手前先填齐）

| 环境变量 | 用途 | 你有吗 | 缺失时的降级 |
|---|---|---|---|
| `LLM_API_KEY` | analyze/genQuestions 报告分析+出题（DeepSeek/通义/GLM，OpenAI 兼容协议） | ✅ 有 | **不可降级**——核心功能，无 Key 这两步直接报错 |
| `LLM_BASE_URL` | LLM 服务地址（默认 `https://api.deepseek.com`） | 跟随 Key | — |
| `LLM_MODEL` | 模型名（默认 `deepseek-chat`） | 跟随 Key | 按你的服务商改 |
| `TENCENT_SECRET_ID` | 腾讯云 ASR 语音转文字（`tencentcloud-sdk-nodejs-asr`） | ❓ **待你确认** | 未配 → mock 模式：空转写 + 手动输入（FR-06 兜底，演示可接受，视频须诚实说明） |
| `TENCENT_SECRET_KEY` | 同上 | ❓ 同上 | 同上 |
| `SUBSCRIBE_TEMPLATE_ID` | finalize 完成通知（一次性订阅消息） | ❌ 需申请 | 未配 → finalize 返回"未配置"，**不影响核心链路**；视频里说明即可 |

**⚠️ 关键澄清点**：你说的"AI 模型 Key 有"——
- 如果是 DeepSeek/通义/GLM 的 Key → 覆盖 LLM，analyze/genQuestions 能跑；
- 但 ASR 用的是**腾讯云 SecretId/SecretKey**（另一套）。
- 请确认是否同时有腾讯云子账号凭证；没有就先走 mock，ASR 转写改成手动输入，核心的"拍照→AI 分析→报告"链路仍可完整演示。

## 1. 开通云开发环境（个人小程序可用，免费额度够演示）

在微信开发者工具里：
1. 顶部「云开发」按钮 → 开通 → 创建环境，记下 `envId`（后续到处要填）。
2. 环境名随意，建议 `facemirror`，计费选「包年包月 · 免费基础版」。
3. 把 `envId` 填进三处：
   - `project.config.json` 的 `cloudfunctionRoot` 同级（若用 cloudConfig）
   - `miniprogram/app.ts` 的 `cloud.init({ env: "你的envId" })`（确认写死 envId，别用 DYNAMIC_CURRENT_ENV 在前端）
   - `cloudbaserc.json` 的 `"envId"` 字段

**判定**：云开发控制台能打开、数据库/存储/云函数三个 tab 都在。

## 2. 部署 10 个云函数 + 注入环境变量

部署顺序（按依赖，无依赖可任意）：

| # | 云函数 | timeout | 依赖说明 |
|---|---|---|---|
| 1 | `login` | 20s | 无外部依赖，最先部署验证连通 |
| 2 | `getQuestions` | 20s | 读题库集合 |
| 3 | `genQuestions` | 30s | 依赖 `LLM_API_KEY`，出题 |
| 4 | `submitPractice` | 20s | 写 practices 集合 + 上传音频到云存储 |
| 5 | `asr` | 60s | 依赖腾讯云凭证或走 mock |
| 6 | `analyze` | 60s | 依赖 `LLM_API_KEY`，生成报告 |
| 7 | `updateTranscript` | 20s | 人工修正转写 |
| 8 | `finalize` | 20s | 依赖 `SUBSCRIBE_TEMPLATE_ID`（缺则跳过） |
| 9 | `getPractice` | 20s | 读单条记录 |
| 10 | `getHistory` | 20s | 读列表 |

部署方式：开发者工具 → 云开发 → 云函数 → 右键每个文件夹「上传并部署：云端安装依赖」。
**注意**：`asr` 和 `analyze` 的 `timeout` 要手动改成 60s（默认 20s 会被强杀，代码里已 config.json 声明，云端部署后仍要在控制台核对）。

**环境变量注入**：每个云函数 → 右键「云函数配置」→ 环境变量，按下表填：

| 云函数 | 变量 |
|---|---|
| analyze, genQuestions | `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` |
| asr | `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY` |
| finalize | `SUBSCRIBE_TEMPLATE_ID` |

**判定**：`login` 云函数右键「云端测试」返回 `{openid: "xxx"}` → 链路通。

## 3. 数据库集合 + 安全规则

代码里出现的集合（grep `db.collection` 实测）：

| 集合 | 用途 | 安全规则（建议） |
|---|---|---|
| `practices` | 练习记录（音频/转写/报告/状态） | 仅创建者可读写：`{"read": "doc._openid == auth.openid", "write": "doc._openid == auth.openid"}` |
| `quota` | 每日配额计数（openid_date_action） | 仅创建者读写 |
| `questions` | 题库（getQuestions/genQuestions 写入） | 全部可读，仅管理端写 |

在云开发 → 数据库 → 逐个新建集合 → 权限设置里选「仅创建者可读写」（questions 选「所有用户可读」）。

**判定**：数据库三个集合都存在，权限不是「所有用户可读写」（否则 IDOR 修复白做）。

## 5. 真机实测用例（逐条，每条留取证）

取证统一放 `facemirror/截图/` 与 `facemirror/演示视频/`，文件名按用例编号。

### A. 登录与权限

**A-01 冷启动登录**
- 前置：已开通云开发、login 已部署
- 步骤：真机扫码进入小程序
- 预期：首页 3s 内加载，Network 里 login 200，Console 有 openid
- 取证：录屏首屏 + Network 截图
- 判定：有 openid 即通过

### A-02 未登录态拦截**（如果前端有这逻辑）**
- 步骤：清除小程序数据后直接访问需要登录的页面
- 预期：跳登录页或提示，不崩

### B. 拍照与上传

**B-01 拍照**
- 步骤：点「开始练习」→ 拍照
- 预期：相机调起，拍照后进入下一步
- 取证：录屏

**B-02 相册选图**
- 步骤：从相册选一张正常人脸照
- 预期：正常进入分析

**B-03 超大图**
- 步骤：选一张 >5MB 图
- 预期：触发大小限制提示，不卡死、不 OOM

**B-04 非人脸图 / 违规图**
- 步骤：选风景照或纯文字图
- 预期：内容安全 msgSecCheck 不误杀正常图；违规图被拦有提示（fail-close）

### C. 录音与 ASR（核心，分有无腾讯云凭证）

**C-01 有腾讯云凭证 · 正常识别**
- 前置：`TENCENT_SECRET_ID/KEY` 已填
- 步骤：录一段 10–30s 语音 → 提交
- 预期：两段式轮询，最终返回转写文本带时间戳
- 取证：转写结果截图 + Network 轮询日志
- 判定：转写非空且语义正确

**C-02 无腾讯云凭证 · mock 降级**
- 前置：不填腾讯云凭证
- 步骤：录一段 → 提交 → 手动输入转写文本
- 预期：`needManual=true`，前端走人工输入框（FR-06）
- 取证：录屏手动输入流程
- 判定：手动输入后能继续进入分析（不卡在 ASR 步）

**C-03 ASR 配额**
- 步骤：同一天连续提交 21 次 ASR
- 预期：第 21 次被 `DAILY_LIMIT=20` 拦，提示「今日练习次数已达上限」
- 取证：第 20、21 次截图对照
- 判定：第 21 次必被拦（B-05 修复点：续查不重复扣配额）

**C-04 越权读他人记录**
- 步骤：用 A 用户的 recordId，在 B 用户登录态下调用 asr
- 预期：返回「记录不存在或无访问权限」（B-01 归属校验）
- 取证：Console 日志

### D. AI 分析与报告

**D-01 正常分析**
- 前置：有转写文本（C-01 或 C-02）+ `LLM_API_KEY` 已填
- 步骤：点「生成报告」
- 预期：analyze 返回五维雷达 + 建议
- 取证：报告页截图 + analyze 返回 JSON
- 判定：雷达数值与建议文本非空

**D-02 LLM 配额**
- 步骤：连续触发 31 次分析
- 预期：第 31 次被 30 次/日配额拦（B-15 修复点）
- 取证：第 30、31 次截图

**D-03 内容安全拦违规转写**
- 步骤：手动输入一段违规文本 → 提交分析
- 预期：msgSecCheck 拦截，不落库（B-12 fail-close）
- 取证：错误提示截图

**D-04 重复提交幂等**
- 步骤：快速双击「生成报告」
- 预期：只产生一条记录
- 取证：数据库 practices 集合截图

### E. 历史与详情

**E-01 历史列表**
- 步骤：完成 ≥2 次练习后进历史页
- 预期：列表显示，分页正常
- 取证：截图

**E-02 详情翻页**
- 步骤：点进任一条详情
- 预期：报告、转写、音频回放都正常

**E-03 越权读他人历史**（B-09 IDOR 修复点）
- 步骤：用 A 的 recordId 在 B 登录态下 getPractice
- 预期：拒绝

### F. 题库与练习

**F-01 题库出题**
- 步骤：进练习页 → 选择题型 → genQuestions 返回
- 预期：返回题目，`LLM_API_KEY` 生效
- 取证：截图

**F-02 练习完成 → 报告**
- 步骤：完成一轮练习 → 报告
- 预期：报告与答题一致

### G. 订阅消息（finalize）

**G-01 有模板 ID · 收到通知**
- 前置：已申请一次性订阅模板，`SUBSCRIBE_TEMPLATE_ID` 已填
- 步骤：完成一次分析 → finalize 触发
- 预期：手机收到一次服务通知
- 取证：手机通知截图 + finalize 返回 `{ok:true}`
- 判定：模板字段 thing1/thing2 与申请时一致

**G-02 无模板 ID · 降级**
- 前置：不填模板 ID
- 步骤：完成分析
- 预期：finalize 返回「未配置」，**核心链路不受影响**
- 取证：Console 日志

### H. 异常与边界

**H-01 断网**
- 步骤：飞行模式下提交
- 预期：超时提示 + 可重试，不崩

**H-02 退出重进**
- 步骤：杀进程后重进
- 预期：状态恢复，历史可继续
