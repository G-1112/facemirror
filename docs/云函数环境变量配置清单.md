# 云函数环境变量配置清单 · LLM_API_KEY（2026-10-27）

> 目的：让 8 个依赖大模型的云函数从「规则/mock 降级」切换为真实 AI 调用。
> 预计耗时：约 5 分钟（每函数 1 个变量，共 8 次粘贴）。

## 一、要配什么

| 变量名 | 值 | 是否必填 |
|---|---|---|
| `LLM_API_KEY` | 你的 DeepSeek API Key（`sk-` 开头，在 https://platform.deepseek.com → API Keys 页面创建/查看） | **必填** |
| `LLM_BASE_URL` | `https://api.deepseek.com` | 可不填（代码默认值即此） |
| `LLM_MODEL` | `deepseek-chat` | 可不填（代码默认值即此） |

> 只配 `LLM_API_KEY` 一个即可，后两项代码里有默认值。DeepSeek 账户需有余额（测试期充值最低档即可）。

## 二、在哪配（逐个函数操作）

1. 微信开发者工具 → 工具栏「云开发」→ 打开云开发控制台；
2. 左侧「云函数」→ 在函数列表中找到下表中的一个函数 → 点进「函数配置」；
3. 找到「环境变量」→ 编辑 → 添加：名称 `LLM_API_KEY`，值粘贴你的 key → 保存；
4. 对下表 8 个函数重复。

| # | 函数名 | 用途 | 配置后效果 |
|---|---|---|---|
| 1 | `parseResume` | 简历解析 | 不再弹「已用规则识别」，AI 结构化解析 |
| 2 | `analyzeJob` | 岗位分析 | 6 维能力评估由 AI 生成 |
| 3 | `genQuestions` | AI 出题 | 自定义出题走真实 LLM |
| 4 | `analyze` | 五维评估 | 练习报告由 AI 评分（走 mock → 真实） |
| 5 | `genDeepQuestions` | 深度面试出题 | 15~20 道强关联追问题 |
| 6 | `deepSession` | 深度面试会话 | 追问/要点提示由 AI 生成 |
| 7 | `deepAnalyze` | 深度面试报告 | 六维雷达 + 优势短板 AI 总结 |
| 8 | `quizScore` | 题库抽题评分 | 逐题点评 + 掌握度 AI 评分 |

## 三、注意事项

- ⚠️ **密钥安全**：key 只配在云函数环境变量里，不要写进代码、不要提交进 git、不要发到群里。
- 环境变量保存后**立即生效**（下次调用即用新值），无需重新上传代码。
- 配完顺手把 `quizScore` 和 `analyze` 的**超时时间改为 60 秒**（同一页面的「函数配置」里，默认 20s 不够 LLM 长任务；项目档案待办 3/8a）。
- 语音识别 `asr` 是另一套密钥（`TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`，腾讯云 CAM 子账号密钥），与本清单无关，未配前转写仍走 mock。

## 四、配完怎么验证

1. 小程序里重新走一遍「深度面试 → 上传简历」：**不再弹出「已用规则识别」**即为生效；
2. 或看云开发控制台 → 云函数 → `parseResume` → 日志：不再出现"LLM_API_KEY 未配置"；
3. 若仍弹降级提示：检查 key 是否粘贴完整（无空格换行）、DeepSeek 账户是否有余额、函数名是否配错环境（云环境 `cloudbase-d1g6atosn49a1b532`）。
