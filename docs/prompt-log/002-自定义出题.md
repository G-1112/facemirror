# Prompt 链 002 · 自定义出题（FR-03，核心差异化）

## 提问

> 用户上传一份简历，我想让 AI 像面试官一样，针对这份简历生成"会问的问题"，
> 而不是随便问"你最大的优点是什么"这种通用问题。Prompt 该怎么写？

## AI 建议

AI 给出"严格面试官"人设 + 三条硬性规则：

1. 每个问题必须针对材料中的**具体内容**（项目名、数字、技术选型、结论）；
2. 优先攻击最薄弱点：数据缺乏对比、结论缺少依据、技术选型未说明理由；
3. 材料中出现数字指标，必须至少追问一次该指标的口径与基线。

## 我如何采纳并改进

1. 输出结构定为 `[{question, target, difficulty}]`，`target` 标明考察点，便于前端展示；
2. 材料文本截断到 4000 字，控制 token 成本；
3. 文档解析失败或 LLM 不可用时降级为 `mockQuestions`（基于材料关键词的通用追问）。

## 引导修 Bug

初版对 PDF 材料直接 `buf.toString()` 得到乱码。我反馈"PDF 解析出乱码"，AI 说明
PDF 是二进制格式需专用解析库，本 MVP 先支持 `.txt/.md/.docx`（docx 用 jszip 解出
`word/document.xml` 里的 `<w:t>` 文本），PDF 列为后续增强。修复后 docx 简历可正常出题。
