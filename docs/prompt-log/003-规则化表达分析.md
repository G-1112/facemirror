# Prompt 链 003 · 规则化表达分析（FR-08，技术亮点）

## 提问

> 除了让 AI 打"表达"分，我还想客观计算语速、口头禅、停顿这些指标，因为 AI 对这些
> 主观又容易算错。这类指标能不能用代码确定性算出来，不依赖模型？

## AI 建议

AI 给出"能确定性计算的，绝不交给模型"的清单：

```
语速(字/分钟)  = 字数 / 有效时长 * 60          // 180-240 正常
填充词密度(%)  = count(["然后","那个","就是","嗯",...]) / 总字数 * 100
口头禅         = 2-gram 高频重复 Top3
长停顿次数     = 相邻句时间戳间隔 > 2s 的次数
时长分配       = 开场/主体/结尾占比，主体 <60% 判结构失衡
```

并建议 `delivery` 维度分数由这些指标加权映射，与 LLM 文字点评互补。

## 我如何采纳并改进

1. 纯函数实现，`miniprogram/utils/expression.ts` 与 `cloudfunctions/analyze/expression.js` 两处逻辑一致；
2. 语速区间 180-240 满分，偏离逐级扣分；填充词密度 >4% 起扣；
3. `paceScore`（节奏）单独由语速映射，与"表达"拆开，凑齐五维雷达。

## 引导修 Bug

初版口头禅统计用"整词匹配"，但中文无空格，2-gram 用 `split("")` 逐字切分，
导致标点也被算进 gram。我反馈"口头禅混进了标点"，AI 建议过滤纯标点组合
（`/^[\p{P}\p{S}]$/u`），修复后 Top3 口头禅回归真实重复词。

## 沉淀

- 落点：`miniprogram/utils/expression.ts` / `cloudfunctions/analyze/expression.js`
- 价值：零成本、更精确、且是区别于"纯 LLM 打分"的工程亮点
