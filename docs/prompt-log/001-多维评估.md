# Prompt 链 001 · LLM 多维评估（FR-07）

## 提问

> 我要做一个面试陪练小程序，用户对着手机回答面试题后，我想让大模型给回答打分。
> 但我不想只得到一个笼统的分数，希望有：分维度打分、逐句批注、优点、改进建议、示范回答。
> 而且 AI 容易乱编，怎么约束它？

## AI 建议

AI 给出"结构化 JSON + 原文照抄证据"的方案：

- 4 个评分维度（相关性/结构/论据/专业度）各 1-5 分；
- 每条优点必须带 `quote`（原话引用）；
- 逐句批注只标有问题的句子；
- 温度 0.2 + 明确禁止项（不得编造转写中没有的内容）。

## 我如何采纳并改进

1. 把"表达"维度从 LLM 中剥离，交给规则引擎计算（见 003），LLM 只评 4 个语义维度；
2. `strengths` 强制 `[{text, quote}]` 结构，`quote` 原文照抄，堵住幻觉；
3. 用 `response_format={"type":"json_object"}` 在协议层约束 JSON，返回后二次校验字段。

## 引导修 Bug

初版 Prompt 让模型直接输出 `sentenceNotes`，结果模型把**每一句**都标了问题（噪声）。
我反馈"逐句批注噪声太多"，AI 建议在 Prompt 里明确"只标有问题的句子，无问题不标"，
并给出 `index` 字段对应原文句序，修复后批注数量明显收敛。
