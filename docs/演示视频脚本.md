# 面镜 · 演示视频脚本（5-8 分钟）

## 分镜

| 时间 | 内容 | 画面/操作 |
|---|---|---|
| 0:00-0:30 | 开场：痛点 + 一句话 | "对着手机说 3 分钟，60 秒拿到能力雷达图" |
| 0:30-3:00 | 主链路演示（真机） | 选场景→抽题→限时录音作答→语音识别→评估报告（雷达图+逐句批注+示范回答） |
| 3:00-3:40 | 核心差异化：自定义出题 | 上传简历 → AI 生成针对性的追问（"模型精度提升12%→追问基线/消融"） |
| 3:40-4:20 | 规则化表达分析 | 展示语速/填充词密度/口头禅/长停顿/时长分配（确定性计算） |
| 4:20-5:00 | 分享海报 + 订阅消息 | 生成海报保存相册 → 报告完成推送订阅消息 |
| 5:00-5:30 | 收尾 | 历史记录、商业闭环简述 |

## 录制要点
- **必须真机**（录音、分享、订阅消息需真机，模拟器不支持）。
- 演示一次完整"录音→报告"链路，报告生成 ≤60 秒。
- 补录一段上传简历生成追问的画面（这是评委最能感知产品深度的点）。
- 结尾截图：体验版二维码（若有，可作为加分项附在提交材料）。
